# Branch Update Drill — Reviewer Runbook

Purpose: walk a new reviewer through what to expect when an open
pull request falls behind its base branch and is then refreshed.

Steps:
1. Open the pull request and note its current head commit.
2. Confirm the base branch has moved ahead with a direct commit.
3. Ask for the pull request branch to be updated from the base.
4. Re-read the pull request: new head commit, changed files, and
   whether it is mergeable.
5. Record the outcome below.

Outcome:
- Head commit before update:
- Head commit after update:
- Mergeable after update:
